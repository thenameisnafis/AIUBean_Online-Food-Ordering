# 🍔 AIUBean - Online Food Ordering System

AIUBean is a Java Swing-based desktop application designed for ordering food within the AIUB university community.  
It works like a simplified version of platforms such as Foodpanda or Foodie, allowing users to browse food providers, place orders, and complete payments in a desktop environment.

The system focuses on demonstrating desktop GUI development, user authentication, admin control, and file-based data handling using Java.

---

## ✨ Features

- User registration and login system
- Separate service provider (restaurant/vendor) registration
- Admin login panel for system management
- Admin can view and delete users and service provider data
- Dashboard for browsing available food providers and menus
- Food item/service viewing interface
- Order placement functionality
- Payment interface with multiple payment method options
- File-based local data storage system

---

## 🛠 Technologies Used

- Java
- Java Swing (GUI)
- Java AWT
- File Handling (Text-based storage)
- Object-Oriented Programming (OOP)

---

## 🎯 Project Purpose

The purpose of AIUBean is to build a simple but functional food ordering system for the AIUB campus community.  
It demonstrates how a desktop application can manage users, service providers, and orders using Java GUI components and file-based persistence without a database system.

---

## 🖥️ How to Run the Project

1. Open the project in any Java-supported IDE (NetBeans / IntelliJ IDEA / Eclipse)
2. Ensure Java JDK is installed (JDK 8 or above recommended)
3. Compile and run the main file
4. Start using the application through the GUI
